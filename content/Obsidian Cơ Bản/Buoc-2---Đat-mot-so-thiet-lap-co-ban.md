1. spell check (if need be)
	![[1-obsidiansetting_spellcheck.png|300]]
2. Set default view và default editing
	![[2-obsidiansetting_defaultviewsetting.png|300]]
3. page preview: nhớ bật chỗ Bookmark và graph view (thường là default)
	 ![[3-obsidiansetting_bookmark-graphview.png|300]]

4. chọn chỗ chứa deleted file location
5. chọn **automatically update internal links** : cái này rất quan trọng, tick chọn để sau này nếu bạn đổi tên 1 file thì nó tự động update trong các file khác được dẫn link.
	![[obsidiansetting_updatelink.png|300]]

Xong rồi, chúng ta bắt đầu ghi chú được rồi đó.

Mỗi lần mở vault, bạn chỉ cần bấm tổ hộp Ctrl O để mở 1 file ghi chú có sẵn, Ctrl N mở note mới, Ctrl T mở tab mới.

Mai ta đi tới cách link note và format sao cho dễ nhìn.

Gửi mọi người 3 kênh hướng dẫn Obsidian căn bản mà theo N đánh giá là logic, dễ hiểu, ứng dụng được liền. Tiếng Anh của các bạn này cũng cơ bản, dễ nghe lắm.
